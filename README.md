# 📷 相机拍摄计算器 (Camera Calculator)

一个纯前端的 HTML 工具，用于计算相机的**拍摄距离与成像大小关系**、**景深 (Depth of Field)** 以及**焦外光斑 (Bokeh) 直径**。

支持主流画幅：中画幅、全画幅、APS-H、佳能 APS-C、索尼/尼康/富士 APS-C、M4/3、1 英寸、手机传感器、电影机 (Super 35) 等。

## ✨ 功能

| 功能 | 说明 |
| --- | --- |
| **画幅选择** | 内置 30+ 种主流传感器规格，自动计算裁切系数与默认弥散圆 (CoC) |
| **等效焦距** | 按裁切系数换算 35mm 等效焦距 |
| **视角 (FOV)** | 水平 / 垂直视角 |
| **成像大小** | 根据被摄物实际尺寸计算传感器上的成像大小及占画幅比例 |
| **放大倍率** | m = f / (u − f) |
| **视野尺寸** | 当前距离下画面的实际覆盖宽度 / 高度 |
| **景深** | 前景深、后景深、总景深、清晰范围、超焦距、入瞳直径 |
| **焦外光斑** | 光斑直径（传感器上）、占画幅比例、像素直径、模糊等级 |
| **可视化** | 景深范围条 + 焦外光斑预览（Canvas 绘制） |
| **中英双语** | 一键切换中文 / English，全部 UI 与传感器名称本地化 |
| **响应式布局** | 桌面端双栏布局、手机端单栏布局，输入面板不悬浮，随页面自然滚动 |

```bash
start index.html

# macOS
open index.html
```

## 🧮 计算公式

### 等效焦距
```
f_equiv = f × 裁切系数
裁切系数 = 43.27mm (全画幅对角线) ÷ 传感器对角线
```

### 视角
```
FOV = 2 × arctan( d / (2f) )
```

### 成像大小 / 放大倍率
```
m  = f / (u − f)
h' = m × h
```

### 景深
```
H  = f² / (N × c) + f              (超焦距)
DN = u(H − f) / (H + u − 2f)       (前景深边界)
DF = u(H − f) / (H − u)            (后景深边界)
```

### 焦外光斑直径
```
A = f / N                                    (入瞳直径)
B = A × |u_bg − u| / u_bg × (f / (u − f))    (点光源)
远景极限：B ≈ A × f / (u − f)
```

其中：
- `f` 焦距，`N` 光圈 f 值，`c` 弥散圆直径
- `u` 对焦距离，`u_bg` 背景距离
- `h` 被摄物实际尺寸，`h'` 成像尺寸

## ✅ 验证

运行内置验证脚本：

```bash
# 计算验证（18 项测试）
node test/verify.js

# i18n 翻译覆盖检查
node test/check_i18n.js
```

覆盖裁切系数、视角、景深、超焦距、放大倍率、焦外光斑等关键计算，以及中英文翻译完整性。

## 📐 支持的画幅

- **中画幅**：Phase One IQ4、富士 GFX、徕卡 S
- **全画幅**：36×24 (135 / FX)
- **APS-H**：佳能 1D Mark IV
- **APS-C**：佳能 (1.6×)、索尼/尼康/富士/宾得 (1.5×)、适马 Foveon
- **M4/3**：17.3×13.0 (2.0×)
- **1 英寸**：13.2×8.8
- **小型传感器**：1/1.7"、1/2.3"、1/2.5"、1/3"
- **手机**：1/1.28"、1/1.56"、1/2"
- **电影机**：Super 35、全画幅电影、M4/3 电影
