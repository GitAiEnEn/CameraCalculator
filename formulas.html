等效焦距

f_equiv = f × 裁切系数

原理

不同画幅的传感器尺寸不同，同样的物理焦距产生的视角也不同。等效焦距是把当前镜头的视角换算成全画幅（36×24mm）下对应的焦距，方便比较。裁切系数 = 全画幅对角线（约 43.27mm）÷ 当前传感器对角线。

视角（FOV）

FOV = 2 × arctan( d / (2f) )

原理

视角取决于传感器某一边的长度（水平/垂直/对角 d）和焦距 f。焦距越短、传感器越大，视角越宽。

  • 水平视角：用传感器宽度代入 d。
  • 垂直视角：用传感器高度代入 d。
  • 对角视角：用传感器对角线代入 d。

成像大小 / 放大倍率

m = f / (u − f) h' = m × h

原理

薄透镜成像公式：1/f = 1/u + 1/v。放大倍率是像高与物高之比，等于 v/u。对远处物体（u ≫ f），像距近似等于焦距，因此像大小近似 h' ≈ h × f/u。

景深（DoF）

H = f² / (N × c) + f DN = u(H − f) / (H + u − 2f) DF = u(H − f) / (H − u)

原理

对焦平面上的点会在传感器上形成清晰的像点；位于对焦平面前后一定范围内的点，其弥散圆直径仍小于允许接受的弥散圆直径 c，因此看起来仍是清晰的，这个范围就是景深。

  • 光圈 N 越大（数值越大），入瞳越小，景深越深。
  • 焦距 f 越长，景深越浅。
  • 对焦距离 u 越近，景深越浅。
  • 弥散圆 c 越小（要求越严格），景深越浅。
  • 当对焦距离等于超焦距 H 时，清晰范围从 H/2 延伸到无穷远。

焦外光斑直径（Bokeh）

A = f / N B = A × |u_bg − u| / u_bg × (f / (u − f))

原理

背景上离开对焦平面的点光源，在传感器上不再是点，而是圆形的弥散斑（光斑）。光斑大小与入瞳直径 A、背景距离 u_bg、对焦距离 u 相关。入瞳越大、背景越远、对焦越近，光斑越大，虚化越强。

远景简化：B ≈ A × f / (u − f)。

景别（人像取景范围）速查

判定公式

程序中人物身高固定为 1.70m（完整全身），景别依据「人物垂直占画面高度」判断。为便于程序使用，各标准区间统一换算为「人物身高 ÷ 取景框竖直高度」的阈值，比例越大人物越充满画面（越近/越紧）。
